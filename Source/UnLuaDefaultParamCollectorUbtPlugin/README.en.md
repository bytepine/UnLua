# UnLuaDefaultParamCollectorUbtPlugin

[中文](README.md) | English

## Overview

This is the C# version of the UnLua plugin's UnLuaDefaultParamCollector module. It allows the engine to use the C# UHT (UnrealHeaderTool), removing the following warning when compiling UnLua on UE 5.1:

```text
DEPRECATED: C++ UHT being used because 'UnLua' does not have a C# version. C++ UHT has been deprecated and will be removed in 5.2
```

## How it works

On engine version 5.1 and later, UnLuaDefaultParamCollectorUbtPlugin replaces UnLuaDefaultParamCollector and exports `DefaultParamCollection.inl` while UHT runs. See `UnLuaDefaultParamCollectorUbtPlugin.cs` for the implementation. The output of both collectors is largely identical, with these differences:

- The C# version adds `// Generated By C# UbtPlugin` to the header. Check for this line in the generated file to confirm that the engine uses C# UHT.
- Generated comments include the `ModuleType` enum name. The new format is `// ModuleName CoreUObject Type EngineRuntime(1)  ModuleGeneratedIncludeDirectory C:/UE5.1/Engine/Intermediate/Build/Win64/UnrealEditor/Inc/CoreUObject/UHT`, whereas the previous format was `// ModuleName CoreUObject Type 1  ModuleGeneratedIncludeDirectory C:/UE5.1/Engine/Intermediate/Build/Win64/UnrealEditor/Inc/CoreUObject/UHT`.
- Some exported types appear in a different order because C# and C++ traverse engine types differently. The exported types and functions are otherwise the same.

Do not remove the original UnLuaDefaultParamCollector: it remains active on engine 5.0 and earlier. Those versions still use C++ UHT; the presence of UnLuaDefaultParamCollectorUbtPlugin does not affect them.

## Notes

UnLuaTestSuite is also a plugin that UHT can invoke (`CanBeUsedWithUnrealHeaderTool` is true in `UnLuaTestSuite.uplugin`), and it does not provide a C# module. A project such as TPSProject that includes UnLuaTestSuite therefore produces another warning:

```text
DEPRECATED: C++ UHT being used because 'UnLuaTestSuite' does not have a C# version. C++ UHT has been deprecated and will be removed in 5.2
```

UnLuaDefaultParamCollectorUbtPlugin removes only the UnLua warning; it cannot remove the warning caused by UnLuaTestSuite. Thus, **a project containing UnLuaTestSuite still invokes C++ UHT during compilation**. Upstream states that production projects do not need UnLuaTestSuite. If UnLuaDefaultParamCollectorUbtPlugin seems ineffective or the UHT warning persists, check whether the project unnecessarily includes UnLuaTestSuite.
